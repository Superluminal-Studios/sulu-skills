# sulu-skills

Public guides for the Sulu API, Sulu MCP render server and Blender add-on submission.
Standalone rules: current branch only; stage exact paths, never `git add -A`; never print secrets; no deploys unless asked.

## Commands

```bash
python3 scripts/validate_skills.py   # release-blocking; enforces connect commands, Blender coordination phrases, private terms
python3 -m unittest discover -s tests -v
```

## Rules

- Public surface only: document endpoints for authenticated users or the public catalog;
  never privileged or service-only routes, infrastructure vendors, data stores, private
  source layout, deployment details, internal role names or private SDK/add-on modules.
- Beyond the one supported Sulu MCP connect command per client and the public `sulu-render`
  SDK commands, do not prescribe local commands, helper programs, filenames or a client.
- Blender submission: prefer Sulu MCP with the `sulu-render` SDK; on the add-on path use
  registered add-on operations through Blender MCP, never raw transfer commands.
- Never include real tokens, signed URLs, credentials or customer data; use semantic placeholders.
- Never recommend a separate validation render; the requested outputs existing locally is completion.
- Agents act within the Sulu MCP project authority set at consent. Ask only when no authority
  exists or a tool returns `approval_required`, for deletion or capacity changes without admin
  access, and before buying credits. No approval packets or per-call confirmations in a skill.
- No skill weakens `GUARDRAILS.md`.
- `api-surface.json` `user_mcp` and the marked blocks in
  `skills/sulu-render/references/user-mcp.md` are generated by the superrepo
  `bin/sync-mcp-surface`; never edit them by hand.

## Changing code

- Never edit or special-case a test to make it pass; if a test looks wrong, say so.
- A bug fix gets a new test only when it touches money, data loss, authorization, the
  render/upload/download path or a production incident; test at the caller's boundary, never
  helpers. Delete obsolete tests with the change.
